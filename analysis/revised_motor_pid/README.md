# 修正参数下的电机辨识与 PID 设计

左侧 2804 带轮架空试验得到一阶速度模型 \(G_m(s)=32.21306/(0.844278s+1)\)。模型输入为 SimpleFOC 的 \(U_q\) 电压指令，输出为左电机相对车身的机械角速度。依据该模型和 20 ms 转速反馈滤波，计算出一组 PI 和三组滤波 PID 候选。整机纵向模型继续使用固定腿构型，车身质量分配、重心与俯仰惯量由实物测定后代入。

## 数据与拟合

使用 `new_homework/evidence/04_left_four_levels` 的 `run_02_L_STEP.csv` 拟合。该轮由 0 跳至 0.30 V，记录包含约 1 s 基线和 4 s 响应。对齐阶跃时刻，扣除基线转速中位数，按原始时间戳求解最小二乘：

\[
\min_{K>0,T_m>0}\sum_k
\Big[K\Delta U_q(1-\exp(-t_k/T_m))-\Delta\omega_k\Big]^2.
\]

一阶试验在轴速列 `omega_rad_s` 上拟合，20 ms 低通 \(H(s)=1/(0.02s+1)\) 在控制设计中单独计入。作业 4.1 的电压标定来自断开电机时的桥臂测试，标定中的占空比和电压不再乘入 \(U_q\) 模型。

### dq 物理模型

左电机线间实测 \(R_{\mathrm{ll}}=6.265~\Omega\)、\(L_{\mathrm{ll}}=1.676~\mathrm{mH}\)，按星形等效得到 \(R=3.1325~\Omega\)、\(L=0.838~\mathrm{mH}\)。参考磁链 \(0.0035~\mathrm{Wb}\) 和 7 对极给出 \(K_e=0.0245~\mathrm{V/(rad/s)}\)、\(K_t=0.03675~\mathrm{N\,m/A}\)，采用相峰值 dq 约定。该约定下的平均电压力矩模型沿用资料中的方程。

\[
L\dot i_q=U_q-Ri_q-K_e\omega,\qquad
J\dot\omega=K_ti_q-B\omega,\qquad
G_{dq}(s)=\frac{K_t}{(Ls+R)(Js+B)+K_eK_t}.
\]

令 \(a=1/T_m\)。由直流增益得 \(B=(K_t/K-K_eK_t)/R\)，将 \(s=-a\) 代入分母得 \(J=[B+K_eK_t/(R-La)]/a\)。重算得到 \(B=7.6765\times10^{-5}~\mathrm{N\,m\,s/rad}\)、\(J=3.07559\times10^{-4}~\mathrm{kg\,m^2}\)：

\[
G_{dq}(s)=\frac{142588.63}{(s+1.184444)(s+3737.132)}.
\]

快时间常数约 0.268 ms，短于采样目标 0.75 ms。快极点由所给绕组参数和慢极点约束得到。\(J,B\) 是当前左侧带轮架空试验的等效量。电机电气与转动方程的经典推导可参考[密歇根大学电机速度建模与根轨迹教程](https://ctms.engin.umich.edu/CTMS/?example=MotorSpeed&section=ControlRootLocus)。

## 经典控制方法计算参数

采用负反馈。\(T_h=0.02~\mathrm{s}\) 为速度反馈滤波时间常数，\(T_f=0.03~\mathrm{s}\) 为设计选取的微分滤波时间常数。比例和积分作用在速度误差上，微分作用在滤波后的测量速度上，因此速度设定阶跃不会直接产生微分脉冲。闭环极点由对测量端的反馈控制律决定。控制器形式可参考 [MathWorks 的 PI-D 控制器说明](https://www.mathworks.com/help/slcontrol/ug/create-i-pd-and-i-pd-controllers.html)。

\[
\begin{aligned}
C_{fb}(s)&=K_p+K_i/s+K_ds/(1+T_fs),\\
D_0(s)&=s(1+T_ms)(1+T_hs)(1+T_fs),\\
D_{cl}(s)&=D_0(s)+K[(K_pT_f+K_d)s^2+(K_p+K_iT_f)s+K_i].
\end{aligned}
\]

取目标多项式
\(D_*(s)=T_mT_hT_f(s+a)^2(s+40)(s+b)\)，其中 \(a=1.4,2.0,2.4~\mathrm{s^{-1}}\) 是三组设计选择。\(s^3\) 项与 PID 增益无关，故 \(b=1/T_m+1/T_h+1/T_f-2a-40\)。若 \([D_*(s)-D_0(s)]/K=n_2s^2+n_1s+n_0\)，依次得

\[
K_i=n_0,\qquad K_p=n_1-T_fK_i,\qquad K_d=n_2-T_fK_p.
\]

以 B 组为例，四个目标极点约为 \(-2,-2,-40,-40.518~\mathrm{s^{-1}}\)。配系数得到 \(K_p=0.072909\)、\(K_i=0.101946\)、\(K_d=0.0006655\)。PI 的情况去掉微分滤波因子，闭环多项式为 \(s(1+T_ms)(1+T_hs)+K(K_ps+K_i)\)。选择 \(-2,-2,-47.1844~\mathrm{s^{-1}}\) 可算出表中的配极点 PI。

各增益单位依次为 \(\mathrm{V/(rad/s)}\)、\(\mathrm{V/rad}\)、\(\mathrm{V/(rad/s^2)}\)。仿真使用 750 µs 控制周期、电压限幅 ±2 V、条件积分和 10 rad/s 给定阶跃。指标按滤波后的速度计算。相位裕度来自连续 dq 线性环路，真实链路延迟与噪声仍需实测。

## 固定腿整机纵向模型

令 \(x,v,\theta,q\) 分别为轮轴位移、对地速度、车身前倾角和俯仰角速度。两轮相同且不打滑时，取平均 \(q\) 轴电流 \(i\)，状态 \(\boldsymbol z=[x,v,\theta,q,i]^\mathsf T\)。两侧轴速相对车身的平均值近似为 \(\omega_{\rm enc}=v/r-q\)。车身上部质量 \(m\) 包括固定舵机、腿、电池和电机固定部分。

\[
\begin{bmatrix}
m+m_w+J_w/r^2 & mh\cos\theta\\
mh\cos\theta & I_b+mh^2
\end{bmatrix}
\begin{bmatrix}\dot v\\\dot q\end{bmatrix}
=
\begin{bmatrix}
\tau/r+mh\sin\theta\,q^2\\
mgh\sin\theta-\tau
\end{bmatrix},\quad
\tau=2(K_ti-B_w\omega_{\rm enc}),\quad
L\dot i=U_q-Ri-K_e\omega_{\rm enc}.
\]

其中 \(m_w,J_w\) 分别为两侧轮端转动部件的合计质量及绕轮轴的合计惯量，\(h,I_b\) 为车身重心至轮轴的高度及绕质心的俯仰惯量，\(B_w\) 为每侧相对运动的等效阻尼。另有 \(\dot x=v,\ \dot\theta=q\)。[参数化模型代码](robot_model.py)返回直立小扰动下的 \(A,B,C,D\)。电气参数可以用左轮绕组与磁链估计作为初始值。台架 \(J,B\) 可用作轮端量级核对，右轮和接地工况需要独立验证。若左右明显不对称，需要分别建模。

整机双环的速度 PI 输出目标俯仰角，姿态 PD/PID 输出共模 \(U_q\)。从整机状态空间模型可计算 \(P_v=v/U_q,\ P_\theta=\theta/U_q\)，据此检查双环极点与裕度。按当前前倾为正的约定，令 \(u=C_{\theta,f}\theta-C_{\theta,r}\theta_{\mathrm{ref}}\)、\(\theta_{\mathrm{ref}}=C_v(v_{\mathrm{ref}}-H_vv)\)，则线性反馈特征式为 \(1-C_{\theta,f}P_\theta-C_{\theta,r}C_v H_vP_v=0\)。同时需用完整闭环状态空间检查内部模式，特别是积分和位置状态。单轮台架 PI 的输出是 V，整机速度外环的输出是 rad，两者增益单位不同。

整机还需装电池后的重量、轮端转动质量分配、轮径、固定腿姿态下车身重心和俯仰惯量，以及同步的 \(U_{q,L/R}\)、左右编码器、俯仰角和角速度、母线电压及采样时间。此次附件记录仅支持左轮架空辨识，右轮对准失败，尚无整机接地状态数据可供拟合。五阶模型的机械矩阵和整机双环增益保留为待测参数。
