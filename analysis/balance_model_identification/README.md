# 固定腿姿态双轮倒立摆仿真与辨识准备

本文件夹是**带假设参数的初步仿真模型**，不是这台机器人的已辨识模型；结果和示例反馈增益不能直接用于实车。当前先建立可替换参数的整机动力学，并说明怎样获取辨识数据。原有 6.1 和 6.2 是单电机电压到转速模型，不是整机平衡模型。

## 1 物理假设与坐标

腿部固定为刚体，两轮在水平面上纯滚动，不打滑；只研究前后方向，忽略转向和腿部柔性。令 x 为轮轴向前位移，θ 为车身向前倾角，τ 为两台电机作用在轮上的**总转矩**；电机对车身施加反作用转矩。状态为 `[x, x_dot, theta, theta_dot]`。正电压对应向前驱动车轮的等效约定；实际左右电机与 IMU 符号必须实测确认。

记车身质量 m、轮组质量 mw（仅轮轴处平动部分）、车身质心到轮轴距离 h、车身绕质心俯仰惯量 I、两轮绝对转动惯量之和 Jw、轮半径 r，有：

```text
M11 = m + mw + Jw/r²
M12 = m h cos(theta)
M22 = I + m h²

[M11 M12] [x_ddot    ] = [tau/r + m h sin(theta) theta_dot²]
[M12 M22] [theta_ddot]   [m g h sin(theta) - tau            ]

omega_rel = x_dot/r - theta_dot
tau = 2 (Kt/R) [Uq - Ke omega_rel]
```

最后一式是等效的低频、电流准静态电压模型，不是完整 PMSM dq 电流动态或电流闭环。两台电机相同，电机角度为相对车身转角；忽略电感、死区、静摩擦、供电降压、磁饱和、电流限制及电机与传感器的延迟。电机参数的线电阻/相电阻、峰值/RMS 和 dq 定义必须统一；此处沿用第 5 节中一组**待复核的换算**，不能视作实测力矩。可参考 [SimpleFOC 电压力矩模式](https://docs.simplefoc.com/voltage_torque_mode)和[双轮倒立摆动力学](https://www.mdpi.com/2076-0825/11/11/339)。

## 2 已知值与示例值

| 参数 | 值 | 来源及状态 |
|---|---:|---|
| r | 0.0425 m | STEP 组件名称标注直径 85 mm；实物有效滚动半径待核 |
| 电池质量 | 0.400 kg | 用户提供，篮子中间；具体位置待量测 |
| 舵机质量 | 4 × 0.120 kg | 用户提供；需避免按舵机 CAD 体积再次计重 |
| 两组电机+联轴器+轮子 | 2 × 0.300 kg | 用户提供；其中转动件与固定件的质量分配未知 |
| 已知质量合计 | 1.480 kg | 不含 PETG、线路及其他未计附件 |
| m | 1.6 kg | 假设，非整机称重，包含固定在车身的部件 |
| mw | 0.4 kg | 假设，为两轮相关平动质量，不能把整组 600 g 全部当轮子 |
| h | 0.15 m | 假设，以车身质心到轮轴为定义 |
| I | 0.012 kg m² | 假设，车身绕自身质心俯仰轴 |
| Jw | 0.00036125 kg m² | 假设两轮合计 0.4 kg 且均为实心圆盘，仅示例 |
| R, Kt, Ke | 3.1325 Ω, 0.0375855 N·m/A, 0.025057 V/(rad/s) | 第 5 节给出的 dq 换算，适配真实 FOC 定义前需复核 |

示例 m+mw=2.0 kg 与 1.48 kg 的已知部件清单并非实测质量分配；它们仅用来运行模型。75% 蜂窝填充、四层壁不能确保打印件平均密度恰为材料密度的 75%，需要称重或切片质量估计。电机定子通常属于车身，转子和轮子按旋转部分建模；避免重复计数。

## 3 仿真结果和局限

运行 `run_simulation.py`，对初始前倾 2°、速度为零的状态做非线性仿真；控制每 5 ms 更新，数值步长 1 ms，Uq 限幅 ±3 V，倾角绝对值达到 35°时终止该工况。图和 CSV 位于 `output`。模型未包含固件实际姿态滤波、编码器误差、通信延迟、轮速滤波、停机逻辑、电气电流动态，不能作为实车安全或稳定性的证据。

三组比较：

1. `open_loop`：Uq=0。
2. `firmware_PD`：Uq=8.8θ+0.29θ̇，采用早期固件的参考值，Ki=0、速度辅助关闭。当前默认参数及复算见[增益计算说明](../revised_motor_pid/balance_defaults.md)。
3. `illustrative_PD_plus_speed`：Uq=30θ+1θ̇+1ẋ。该速度反馈以 m/s 为输入，**不是固件现有速度辅助环**，没有仿真固件中的速度滤波、积分及限幅。此组只演示反馈结构，不能直接烧录。

该示例下开环与默认 PD 分别在约 0.357 s、0.447 s 达到 35°；第三组 5 s 末倾角约 0.030°。线性模型中 x 无位置反馈，存在零特征值，不能把倾角收敛解释为整机位置渐近稳定。不同质心高度下第三组线性结果：h=0.10、0.15 m 时非位置模式实部为负；h=0.20、0.25 m 时存在正实部。只说明该**假设模型**对 h 敏感，不确定实际机器人是否处在这些情况。

## 4 从初始模型到实际辨识

1. 固定腿姿态，装上电池及全部电子部件，称整机重量。确认轮子实际有效滚动半径和轴线；记录各部件是否包括在称重与 CAD 中。
2. 估计车身质心及俯仰惯量：优先从具有可信部件质量的 CAD 导出，电池用 400 g、每个舵机用 120 g、每组轮驱 300 g 但拆分为机身固定和轮端旋转部分。若无法拆分，至少对 h、I 和轮端质量给出范围并做敏感性分析。安装位置和惯量不能仅由总重量确定。
3. 单轮分别做低电压、小幅多工况记录，保存时间戳、命令 Uq、轮速、母线电压、两轮和 IMU 的实际采样时间；条件允许时记录相电流或经校准的力矩。已有四档开环数据可以用于电机侧初步比较，但它们是单电机数据，不能直接辨识车体的 m、h、I。实验必须受支撑并设实体断电，严禁借未知增益自由运行。
4. 两轮固定在同一姿态、车体受限且有人保护的条件下收集小幅扰动响应和驱动输出，记录 angle/rate、左右轮速、Uq、状态和供电，附上是否扶持、接地和驱动模式。将扶持力当作未知扰动，不能用强扶持数据直接当自由车体动力学；先检查标定、方向、时延、饱和和左右一致性。
5. 将可测参数固定，对可辨识参数做约束拟合，留出独立试验数据验证；报告拟合区间、残差、可信范围和不确定性。仅有一条单电机转速曲线时，无法唯一确定整车质量、质心、惯量和电机力矩常数。
6. 在经验证模型及参数范围上考虑完整采样、估计滤波、速度环和电气饱和，比较稳定裕度、控制余量与鲁棒性后，再输出带单位的候选控制参数；低风险、受约束测试后再决定固件修改。

## 运行

```powershell
python analysis/balance_model_identification/run_simulation.py
python -m unittest tests.test_balance_model_identification
```

需 Python、NumPy、Matplotlib。测试覆盖零点平衡、重力趋势、力矩反作用方向和小信号线性化一致性。模型仍需与实车数据对照验证。
