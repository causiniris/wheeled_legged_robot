# 固定腿姿态的速度环与姿态环模型

## 1 目标和边界

本模型用于前后直立和平面直线速度控制，不含舵机关节驱动、腿部摆动和左右差速转向。舵机、固定腿、固定电机部件、电池和结构件的质量和惯量仍属于车身。假定腿已可靠固定，轮地面纯滚动、两侧轮径相同、左右驱动近似对称。此模型不是实车辨识结果。

控制结构：

```text
前后速度目标 v_ref
        ↓
速度误差 → 速度 PI → 目标俯仰角 θ_ref（±3°）
                          ↓
                 姿态 PD → Uq（±3 V）
                          ↓
                双轮电机 + 倒立摆车身
                          ↓
            轮速/位置反馈 ← 编码器与姿态估计
            角度/角速度反馈 ← IMU
```

此处假定前进速度、前倾角和推动轮子前进的电压均为正。实际硬件必须单独核验传感器方向、左右电机方向及动作方向。

## 2 被控对象的状态方程

令 x 为轮轴沿地面位移，v=ẋ，θ 为前倾角，ω=θ̇，状态 `s=[x,v,θ,ω]ᵀ`。两个对称电机的总力矩为 τ，轮对地纯滚动，简化力矩表达式采用 `τ = 2 Kt/R (Uq - Ke(v/r-ω))`。该式是准静态电压模式近似，忽略电流动态，且电机 dq 参数尚需在 SimpleFOC 中验证。

线性化后的状态方程为 `ṡ=A s+B Uq`。当前假设模型得到：

```text
A = [0   1        0          0
     0  -0.4036 -11.7720     0.01715
     0   0        0          1
     0   2.31294 107.9100   -0.09830]
B = [0, 0.68462, 0, -3.92306]ᵀ
```

此组数值对应车身 1.6 kg、轮相关平动质量 0.4 kg、车身重心高 0.15 m 等假设；轮径 85 mm 仅来自 STEP 组件名称。它们尚未辨识，不代表真实车体。非线性完整方程与其他参数见本目录 `README.md` 和 `model.py`。

## 3 双环方程

模型将实际地面速度 v 经一阶滤波得到 vf；外环 PI 将速度误差转换为目标倾角：

```text
Tf v̇f = v - vf
e_v = v_ref - vf
ż = e_v
θ_ref = sat(Kvp e_v + Kvi z, ±θmax)
Uq = sat(Kpθ(θ - θ_ref) + Kdθ ω, ±Umax)
```

速度目标向前时 θ_ref 为前倾；姿态环电压的符号按第 2 节定义。速度 PI 在倾角目标饱和时使用条件积分；当前演示没有在电压饱和时冻结外环积分，也没有模拟 IMU 滤波、控制延迟和过倾停机状态机。稳态直立角应以实际质心和传感器校准确定，示例暂取 0。

无饱和的连续时间双环模型可使用六个状态 `[x,v,θ,ω,vf,z]ᵀ`：其中前四个是机械状态，vf 是速度滤波状态，z 是外环积分状态。输入为速度参考 v_ref。由于示例脚本采用 5 ms 离散更新、限幅和抗饱和，实际仿真是分段非线性离散控制系统，并非仅靠上述连续线性模型就能证明稳定。

更具体地，设 `cθ=[0,0,1,0]`、`cω=[0,0,0,1]`、`cv=[0,1,0,0]`，则增广状态空间矩阵可写为：

```text
           [ A+B(Kpθ cθ+Kdθ cω)    B Kpθ Kvp   -B Kpθ Kvi ]
A_aug  =   [ cv/Tf                  -1/Tf         0        ]
           [ 0 0 0 0                -1            0        ]

B_aug  =   [ -B Kpθ Kvp ]  （此块为 4×1 列向量）
           [ 0           ]
           [ 1           ]
```

即 `[ṡ, v̇f, ż]ᵀ = A_aug [s, vf, z]ᵀ + B_aug v_ref`。此写法没有纳入姿态传感器滤波、电压限幅及速度参考的动态变化限制。

本示例采用姿态 PD，便于建立串级环路；后续可在已辨识模型上评估以 LQR 替代或重构内层状态反馈，但需要统一参考值和速度状态，避免直接叠加两个都强力调节速度的控制器。

## 4 与现有固件的区别

现有 `V1_06` 固件的速度辅助默认关闭；其输入是两个电机相对于车体的编码器角速度平均值，采用 deg/(rad/s) 和 deg/rad 单位，并用于零速度辅助；本仿真输入是**地面线速度 m/s**，可设置速度目标。仿真参数、滤波对象和接口不等同于现有固件，不能把示例参数直接写入固件。

若编码器测量的是轮相对车身转速且轴向符号一致，无滑动时近似关系为 `v = r(平均轮相对角速度 + 车身俯仰角速度)`；偏心、传感器安装、正方向和单位要实测核对，滑动时关系失效。当前脚本直接读取理想模型的 v，未建立编码器测量误差模型。

## 5 仿真工况及结果

运行 `python analysis/balance_model_identification/run_cascade_simulation.py`，控制周期 5 ms、积分步长 1 ms，1 s 时速度从 0 跳至 0.05 m/s，12 s 时降到 0；零初始角和速度。示例姿态 PD 为 30 V/rad、1 V/(rad/s)，外环速度 PI 为 0.03 rad/(m/s)、0.005 rad/m；均为假设模型中的**演示数值，不能用于实车**。

此示例完成 20 s 仿真，峰值姿态约 1.20°，峰值指令约 0.64 V；速度约在 3 s 时出现约 0.19 m/s 峰值，相对 0.05 m/s 的目标**明显超调**，因此不是合格的优化参数。仿真只说明模型和两环能够运行，不能证明实际机器人可稳定。曲线和数据见 `output/cascade_speed_response.png`、`output/cascade_speed_response.csv`。

## 6 必须测量的数据

| 优先级 | 测量项 | 用途和建议方法 |
|---|---|---|
| 必须 | 实际构型的整机总质量，kg | 固定腿、装入电池及全部线路后称重；不必把已装舵机重复加一次 |
| 必须 | 车身质心相对轮轴的前后偏移和高度，m | CAD 指定实际部件质量后导出；或对实车采用多姿态支承称重/悬挂法测量并记录误差 |
| 必须 | 车身绕质心的俯仰转动惯量，kg m² | 用分件 CAD 质量属性及平行轴定理，或采用可重复的小角度摆动试验求得；记录是否绕轮轴、质心或其他轴，不能混用 |
| 必须 | 有效轮径与轮距，m | 轮径测实际接地滚动周长；轮距用于以后差速/转向，前后对称模型不直接使用轮距 |
| 必须 | 两侧相对编码器转角、转速及方向 | 架空手转和低电压测试，确认正向、分辨率、速率、延迟；与 IMU 角速度符号对齐 |
| 必须 | 两侧电机命令电压、实际母线电压及转速 | 两轮分别多工况记录时间戳和 Uq，验证左右差异、死区、饱和与电压降；空载结果不能直接等同负载力矩 |
| 必须 | IMU 俯仰角、陀螺角速度、轴向、偏置、安装位姿、频率和延迟 | 静止、缓慢倾斜及受控小角度转动时记录；检查角与角速度的一致方向及滤波延迟 |
| 必须 | 现有固件实测状态和日志 | 输出 `A/F/u/pitch/rate/wl/wr/imu_us/foc_us` 及 STOP/FAULT；先定位轮子不上力。20 Hz 日志不能评估高频闭环 |
| 强烈建议 | 轮及转子实际转动惯量 Jw；每侧 300 g 中固定和旋转质量分配 | CAD 给定材料与实测部件质量，或拆分称重并做摆动测试，避免将整个电机 300 g 都当转动轮 |
| 强烈建议 | 电机相电阻、相电感、Ke、Kt、最大连续电流及峰值电流 | 明确线/相、峰值/RMS、dq 口径与驱动限制；电流或受控力矩测量有助确认有效力矩。不能只用开环转速拟合唯一确定全套参数 |
| 强烈建议 | 数据记录频率、速度环/姿态环实际周期、FOC 间隔和抖动 | 测真实周期、延迟；200 Hz 为配置目标，不代表实际稳定频率 |
| 后续 | 电池状态、接地摩擦与打滑、驱动器温升和电源限流 | 为限幅、鲁棒性和硬件能力验证提供边界 |

## 7 建议测量与辨识顺序

1. 检查驱动使能及方向；分轮测试并留存日志。
2. 测整机质量、轮径、重心和车身惯量；记录电池位置、腿固定姿态与已安装部件。
3. 两侧分别采集受控小电压阶跃的 Uq、转速、电源及时间戳；有条件增加电流和电机温度。用多个档位估计有效电机模型并留独立数据校验。
4. 在支撑与限位条件下记录 IMU 和编码器的同步小角度运动与控制响应；标注扶持方式。扶持力不可忽略，不能把有人扶持时的曲线直接当作自由系统用于无偏辨识。
5. 用已测参数建立参数范围，并对保留数据评估预测误差、时延、饱和、左右差异；之后再调速度环和姿态环，并在离散非线性仿真中比较 PD/PI 与 LQR 方案。

上电对齐时两轮可能转动；实测应支撑车身、保证轮子空间并具备可立即切断驱动电源的开关。当前固件电压限制并非电流限制。
