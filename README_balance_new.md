本版按你确认的方案工作：ESP32 Dev Module、两块 SimpleFOC Mini、两台 2804、两只 AS5600、一个 MPU6050。四个 STS3215 **先固定姿态**，本程序不发送舵机命令。腿部必须已通过机械固定或独立的舵机控制保持姿态；本程序不会自动让舵机上力，也不会从趴地状态自行起立。

## 1. 接线与安装

| 设备/信号 | 第一路（左轮） | 第二路（右轮） |
|---|---|---|
| SimpleFOC Mini IN1 / IN2 / IN3 | GPIO32 / GPIO33 / GPIO25 | GPIO14 / GPIO27 / GPIO26 |
| SimpleFOC Mini EN | GPIO12 | GPIO13 |
| AS5600 SDA / SCL | GPIO21 / GPIO22 | GPIO19 / GPIO18 |
| MPU6050 SDA / SCL | GPIO21 / GPIO22，与第一只 AS5600 并接 | 不接第二总线 |

- 两只 AS5600 都是地址 `0x36`，因此分开使用两条 I2C 总线；MPU6050 默认为 `0x68`。MPU6050 AD0 接地；若确实接到 3.3 V，则将 `MPU6050_ADDRESS` 改为 `0x69`。
- AS5600 使用 3.3 V 逻辑。MPU6050 模块按自身供电标识接线，确保 SDA/SCL 上拉到 **3.3 V**，不能让 ESP32 的 I2C 引脚承受 5 V。
- ESP32、两块驱动、两个编码器、MPU6050、电机电源负极共地。两块驱动用电机电源，舵机由匹配其规格的独立供电供电，不从 ESP32 的 3.3 V 引脚取舵机功率。
- 第一组相线顺序沿用作业的 `32/33/25`，不是上游的 `25/32/33`。每次复位均重新执行 FOC 对齐。
- `POLE_PAIRS=7`、`SUPPLY_VOLTAGE=12`、10 kHz PWM 和 3 V q 轴限幅来自旧作业配置，仍需与两台实际电机、电源核对。2804 尺寸名称本身不能证明极对数和相电阻。
- 没有电流传感器，也未假设相电阻。**3 V 限幅不是 3 A 电流限制**，受阻、持续饱和时应停机检查温升和供电。
- GPIO12 是旧作业沿用的启动配置脚，驱动 EN 不应在 ESP32 复位时将它拉高；若出现启动失败，先检查该电平。
- MPU6050 固定在刚性车架上。默认传感器 **X 轴平行车轮轴，Z 轴大致朝上**。若车轮轴平行传感器 Y 轴，在 `BalanceController_new.h` 改 `IMU_PITCH_AXIS='Y'`；它不是只改正负号就能替代的选择。

实际编译使用 SimpleFOC 2.3.3 的 ESP32 MCPWM 驱动：两路分别使用 MCPWM0 的 A/B 输出，PWM 计时基准共享，因此两路均设置为同一 10 kHz。

## 3. 第一次启动必须按顺序完成

1. **支撑车身并架空车轮**，确保四个关节不会塌下。上电后左右轮依次 FOC 对齐，会先转动；这一阶段尚不处理串口 `X`，需要停机时断驱动电源。不能把“默认未使能平衡”理解为初始化阶段轮子绝不转动。
2. 对齐结束出现 `CALIBRATE` 时，保持你希望的直立姿态静止约 1.5 秒。程序检查加速度和陀螺仪波动，失败会显示 `FAULT` 并禁止使能；检查姿态/接线后复位。显示 `Ready but disarmed` 才能开始后续操作。
3. **检查 MPU6050 方向**：不使能，轻轻向前倾。`pitch-set` 应增大；前倾运动过程中 `rate` 应为正，停住后 `rate` 回到接近 0。向后倾相反。如果完全不随前后倾变化，先改轴 `X/Y`；若角度和角速度均反向，改 `IMU_PITCH_SIGN` 的正负并重新烧录。不要带着错误轴向去增大 Kp。
4. 扶正、停住轮子，分别发 `L`、`R`。每条命令只驱动对应轮 **0.5 V、200 ms**，随后自动关闭；每次等待完全停下再测试。观察轮胎最上缘是否朝车头运动，即落地后会推车向前。哪侧相反，就只改那侧 `LEFT_MOTOR_SIGN` 或 `RIGHT_MOTOR_SIGN` 并重烧。未转动时不能判定方向，应先检查相线/磁铁/负载；不要通过跳过方向检查来试平衡。
5. 方向都正确后再进行扶持下的地面测试。保持机身距校准平衡角不超过 8°、轮子静止，发送 `A`。前倾应向前追、后倾应向后追；若相反或剧烈振荡，立即 `X`。初次不要完全放手。
6. 初始姿态设得不准确时，先 `X`，扶到新的预期直立姿态后用 `C` 重新静态校准。小幅偏差用 `+/-`，每次 0.1°，相对校准姿态最多调整 ±5°。这是人工确定参考角，并非算法自动识别重心位置。

电源复位、串口监视器触发板子复位时，都可能重新执行第 1 步的轮子对齐。

## 4. 串口命令与调参

波特率 115200。PlatformIO 本环境移除了 `send_on_enter`，单字符按键即可发送；Arduino IDE 串口监视器需点击发送。所有增益/角度调整仅在停机后生效，运行中只处理 `X`。一次发送一条命令。

| 命令 | 动作 |
|---|---|
| `A` | 启动平衡；要求最新有效 IMU、接近直立且轮子静止 |
| `X` | 关闭两路 EN 和输出 |
| `L` / `R` | 限时单轮正向测试，只在架空车轮时使用 |
| `C` | 静止重校准陀螺零偏和直立参考角 |
| `+` / `-` | 平衡参考角增加/减少 0.1° |
| `1` / `0` | 倾角 Kp 增加/减少 0.5 |
| `3` / `2` | 角速度 Kd 增加/减少 0.02 |
| `V` | 切换慢速轮速 PI 外环；默认关闭 |
| `?` | 查看当前 Kp、Kd、参考角、方向和速度环状态 |

初值：Kp=8.8 V/rad、Kd=0.29 V/(rad/s)，电压限制 ±3 V。**这些是起调值，不是实车辨识结果。** 上游代码设置了 `phase_resistance=2.9` 并做另外的数值转换，本版没有假设该电阻，所以同名数值不代表同样扭矩输出。

建议先只用姿态 PD：纠偏方向正确但追不上时，小步增加 Kp；来回明显振荡时，停机后适度增加 Kd 或减小 Kp。先排除机械松动、轮子打滑、轴向错误和驱动力不足。若输出长期顶到 ±3 V，单纯增益加大不一定有用，应检查负载和可用转矩，不自动提高输出上限。

姿态环已经能短时稳定后，如仍一直跑偏，可先调整参考角，再 `X` 后用 `V` 打开慢速度环，最后 `A`。速度环用带限幅/抗积分饱和的后仰/前倾参考来减速，最大偏移 ±3°；速度向前时给出向后的倾角目标。它不是定点位置环，也没有航向控制，不能保证原地不移动或不转弯。

串口调参保存在 RAM，复位会恢复初值。验证成功后，将值写入 `BalanceController_new.h` 的 `INITIAL_ANGLE_KP`、`INITIAL_ANGLE_KD` 等配置再编译；方向必须在源文件中修改。

输出例（仅字段说明，不是实测数据）：

```text
pitch=... set=... rate=... wl=... wr=... u=... lean=... A=0 T=0 F=0
```

`pitch/set/lean` 单位度，`rate` 度/秒，`wl/wr` 按配置方向换算为轮子 rad/s，`u` 是共同 q 轴电压命令。`A` 为平衡使能，`T=1/2` 为左右单轮测试，`F=1` 为故障锁定。

## 5. 停机与验证边界

- 超过校准直立角 ±35°或轮速绝对值超过 30 rad/s 会停机，需扶正、轮子停下后重新发 `A`。
- I2C 错误、短读、磁铁状态异常、MPU6050 数据不合理或控制间隔超 30 ms，会锁定故障，禁止再次 `A`；检查修复后复位。I2C 超时设置为 3 ms。
- EN 在进入库停机方法之前先拉低，只有已初始化并链接成功的驱动才调用库停机函数。
- 遥测 5 Hz，串口发送空间不足时丢弃该帧。FOC 循环连续运行，姿态环目标频率 200 Hz；实际频率需在实车上测量。
- 超时检查在主循环恢复执行时触发，不是独立硬件急停/看门狗；完全死机、掉电、机械倒塌不能靠这些软件检查补救。
